One line, big laugh: **"WARNING: This human will insist it is fine while visibly on fire, then ask if anyone else smells smoke."** — the safety warning label that should come printed on every human being. The laugh lands in the last few words, and it is funny because it is true: people insist they are fine while the evidence is burning right in front of everybody, then notice what everyone else already saw.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, standard library only) writes the single 103-character line to `/output/entry.txt` and prints exactly that line to stdout. No network, no randomness — every run writes the same bytes.
